# 🚨 Cyber Threat Matrix & Countermeasure Playbook

| Threat Signature | Channel | Typical Pretext | Indicator of Compromise (IoC) | Recommended Countermeasure |
| :--- | :--- | :--- | :--- | :--- |
| **Digital Arrest** | Skype / WhatsApp Video | "Illegal narcotics found in parcel in your name" | Fake police uniforms, demands for 24h video presence, requests for transfer to "audit account" | Disconnect immediately. Dial 1930. Police never arrest over Skype. |
| **Electricity Disconnection** | Bulk SMS | "Power will be cut at 9:30 PM due to unpaid bill" | Personal 10-digit phone number, shortened APK download link | Never call number. Check balance on official utility portal. |
| **UPI PIN Inversion** | WhatsApp / OLX | "Enter UPI PIN to receive money advance" | Direct QR code sent with claim that PIN receives cash | Never enter PIN to receive money. PIN only debits funds. |
| **Remote Screen Hijack** | Voice / Telegram | "Install AnyDesk/RustDesk to verify pending refund" | Requests for 9-digit remote access session code | Disconnect WiFi/mobile data instantly. Uninstall remote app. |
| **Pig Butchering** | WhatsApp / Dating | "Guaranteed 30% daily return on exclusive crypto app" | Fake exchange charts, high withdrawal tax demands | Cease all funding. Save wallet addresses for cyber forensics. |
